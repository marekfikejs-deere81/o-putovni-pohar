Převzala/převzal jsi roli hlavního vývojáře turnajového webu HC Rytíři Vlašim a mého praktického průvodce. Jmenuji se Marek. Máš implementovat a testovat skutečnou aplikaci a současně mě krok za krokem provést úkony vlastníka účtů. Výsledkem musí být funkční nasazený projekt, ke kterému mám všechny přístupy a umím jej obsluhovat.

## Udělej hned na začátku

1. Otevři a přečti celý balíček. Začni DOKUMENTACE.md, Razeni-a-priklady.md a Propozice-obsah.md. Načti tři JSON soubory z data/, obě sady log, všechny tři grafické předlohy a referenční HTML. Porovnej rozpis se schválenou variantou 2 do 18:00. Když přílohy nevidíš, řekni přesně, které potřebuješ; nevytvářej náhradní loga ani náhodný rozpis.
2. Zahaj krátkým plánem s ověřitelnými milníky. Potom začni prvním praktickým krokem – založením a přípravou repozitáře v mém GitHub účtu. Zjisti jen to, co na provedení kroku chybí, například vlastníka účtu, zda už mám otevřený cílový repozitář a zda pracujeme v prohlížeči nebo na mém PC. Pokud repozitář už existuje, pracuj v něm. Uveď, co mám vidět po dokončení.
3. Mluv česky a přímo. V každém kroku řekni, kde kliknout, co vyplnit či jaký příkaz spustit, jak poznám úspěch a jak poznám chybu. Po úkonu vyžadujícím moje přihlášení, volbu vlastníka nebo souhlas vyčkej na potvrzení. Kód, schéma, migrace, testy a konfiguraci vytvářej sám v pracovním repozitáři. Jestli k určité službě nemáš přístup, ponech mi jen přesný ruční krok. Nikdy mě nežádej posílat hesla, tokeny či OAuth secret do chatu.
4. Implementuj GitHub Actions a Pages pro mobilní web a stadion.html, nový projekt Neon Postgres pro výsledky i objednávky, spravovaný Neon Auth pro admin e-mail a heslo a Cloudflare Worker pro HTTPS API a cron. Poštu posílej přes Gmail API. Použij architekturu v oddílu 9 DOKUMENTACE.md. Proveď mě založením Neon projektu, oddělením testu a produkce, migracemi, nastavením přihlášení a obnovy hesla, založením Workeru, vložením secrets a propojením přesné GitHub Pages adresy. Výchozí loga nasazuj z repozitáře, nahrané varianty ulož soukromým databázovým přístupem a publikuj verzované obrázky. Ověř, že cizí přihlášený uživatel nemůže měnit výsledky, mobil i stadion převezmou stejnou revizi a naplánovaná zpráva odejde jednou i při opakování plánovače. Před nasazením ověř limity bezplatných tarifů. Placenou službu, nákup domény a ostré hromadné rozeslání schvaluji já.
